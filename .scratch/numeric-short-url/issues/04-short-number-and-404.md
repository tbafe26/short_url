# 04: 단축 번호 정규형과 404 안내

**What to build:** 정규형 단축 번호(1 이상, 앞자리 0 없음, `i64` 범위)만 이동 대상으로 인정한다. 존재하지 않는 번호와 비정규형 숫자 경로는 알아볼 수 있는 404 안내 페이지로 응답한다. 안내 페이지에는 생성 화면으로 돌아가는 링크가 있다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 없는 번호, `/0`, `/0123`, `/99999999999999999999`가 모두 상태 코드 `404`와 안내 HTML을 응답한다 (경계 1 테스트)
- [ ] `i64::MAX`와 `i64::MAX + 1` 경계값은 단축 번호 파싱 단위 테스트로 확인한다
- [ ] 안내 페이지에 생성 화면(`/`)으로 가는 링크가 있다
