## Comments

- 구현 완료(`src/main.rs`): 복사 버튼, 생성 중 비활성/진행 중 상태, 연속 생성. fmt/clippy 2종/test/`dx build --release`/`dx serve`(페이지에 "숫자형 단축 URL" 포함) 확인.
- 앞 세 항목은 브라우저에서 직접 클릭해 확인하지 못했다(헤드리스 환경). 사람의 브라우저 확인 뒤 체크한다. 그래서 상태는 resolved로 바꾸지 않았다.
- (09 작업 중 추가 확인) 앱 내장 브라우저로 Worker(`wrangler dev`)를 거친 화면을 눌러 확인했다.
  - **복사**: 내장 브라우저는 클립보드 쓰기 권한이 `denied`라 실제 복사는 불가능하다. 그래서 `navigator.clipboard.writeText`를 기록용 함수로 바꿔 놓고 버튼을 눌렀다. 단축 주소가 정확히 전달됐고 "복사했다"가 표시됐다. 실제 클립보드 복사는 배포 후 일반 브라우저에서 확인한다.
  - **연속 생성**: 새로고침 없이 `/3` → 오류 입력 → `/4`로 이어서 생성됐다. 이전 오류와 복사 표시는 지워진다.
  - **진행 중 상태**: 로컬 응답이 너무 빨라 눈으로 확인하지 못했다. 코드상으로는 요청 중 `disabled`와 "생성 중..."을 표시한다. 그래서 체크하지 않았다. 배포 후 Railway 절전에서 깨어나는 느린 첫 요청 때 확인할 수 있다.
