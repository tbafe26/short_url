# 06: 복사 버튼과 생성 UX

**What to build:** 방문자가 생성된 단축 주소를 버튼 하나로 복사하고, 복사 성공 표시를 본다. 생성 중에는 버튼이 진행 중 상태가 되어 중복 클릭을 막는다. 생성 후에도 새로고침 없이 다른 URL을 이어서 단축할 수 있다. 수정·삭제 UI는 없다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 복사 버튼이 단축 주소를 클립보드에 넣고 성공 표시를 보여 준다
- [ ] 생성 요청 중에는 생성 버튼이 비활성·진행 중 상태다
- [ ] 연속으로 여러 URL을 생성할 수 있다
- [ ] `dx build --release`가 통과한다
